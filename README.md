## ⚙️ Funcionalidades

- Listagem de tarefas
- Criação de nova tarefa
- Edição de tarefa existente
- Marcar tarefa como concluída
- Exclusão de tarefa

## 🚀 Como rodar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- [MySQL](https://www.mysql.com/) rodando localmente

### Instalação

```bash
# Clone o repositório
git clone https://github.com/Renan-Lopes7/nodejs-ToDo-mvc-sequelize.git

# Acesse a pasta
cd nodejs-ToDo-mvc-sequelize

# Instale as dependências
npm install
```

### ⚠️ Configuração do banco de dados

Antes de rodar, abra o arquivo de configuração do banco e substitua os campos de usuário e senha pelas suas credenciais do MySQL.

### Execução

```bash
# Desenvolvimento
nodemon
```

Acesse em: [http://localhost:3000](http://localhost:3000)

## 🛠️ Tecnologias

- **Node.js** — runtime JavaScript
- **Express** — framework web
- **Sequelize** — ORM para banco de dados
- **MySQL** — banco de dados relacional
- **Handlebars** — template engine
- **Nodemon** — reload automático em desenvolvimento
- **MVC** — arquitetura do projeto
